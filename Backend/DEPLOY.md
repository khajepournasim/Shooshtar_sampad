# راه‌اندازی نسخه واقعی پنل دانش‌آموزی

این پروژه دو حالت دارد:

1. **نسخه نمایشی روی GitHub Pages**: صفحات سایت و پنل نمونه کار می‌کنند، ولی اطلاعات دانش‌آموزان واقعی داخل GitHub Pages قرار نمی‌گیرد.
2. **نسخه واقعی با Backend**: پوشه `backend` یک سرور Node.js و SQLite دارد. برای استفاده واقعی:
   - Node.js نصب کنید.
   - داخل `backend` دستور `npm install` بزنید.
   - متغیر محیطی `JWT_SECRET` را با یک مقدار تصادفی طولانی تنظیم کنید.
   - دستور `npm start` را اجرا کنید.
   - سایت از `http://localhost:3000` قابل مشاهده است.
   - دانش‌آموز نمونه: کد ملی `1000000001` و رمز `123456`.

برای تولید واقعی مدرسه، قبل از ورود اطلاعات واقعی:
- رمز نمونه را تغییر دهید.
- HTTPS فعال کنید.
- مدیریت کاربران را به پنل مدیر متصل کنید.
- برای هر دانش‌آموز رمز جداگانه ایجاد کنید.
- کارنامه و رضایت‌نامه‌ها فقط بعد از احراز هویت سمت سرور ارائه شوند.
- از نگهداری اطلاعات حساس در localStorage یا HTML عمومی خودداری کنید.
