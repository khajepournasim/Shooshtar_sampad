# نسخه جدید سایت دبیرستان استعدادهای درخشان شوشتر

## تغییرات این نسخه
- پنل دانش‌آموزی از صفحه اصلی حذف شده و فقط دکمه ورود در هدر باقی مانده است.
- صفحه ورود دانش‌آموز با کد ملی به API واقعی Cloudflare D1 وصل می‌شود.
- میثاق‌نامه و تعهدنامه دو بخش کاملاً مستقل در `documents.html` هستند.
- بخش «کادر و همکاران» شامل مدیر، معاونان، مشاور و دبیران است.
- آدمک صفحه اول حذف شده و موشن‌ها به حلقه‌ها، نقاط نورانی و خطوط تمیز تبدیل شده‌اند.
- افتخارات با نام + رشته/عنوان + رتبه نمایش داده می‌شوند و پایه تحصیلی در کارت افتخارات نمایش داده نمی‌شود.
- زهرا چیت‌سازی در افتخارات این نسخه وجود ندارد.
- سرگروه مرحله ملی تفکر سیستمی و حکمرانی داده‌محور: سیده زینب مرعشی.
- پیام ارتباطی از حالت خطای مبهم به API واقعی منتقل شده است.

## پنل دانش‌آموز
برای اینکه ورود واقعاً کار کند، D1 باید به Worker وصل شود. `wrangler.toml` را باز کنید و فقط `database_id` را با شناسه D1 خودتان عوض کنید. سپس جدول‌ها را با `worker/schema.sql` بسازید.

API را روی Cloudflare Worker منتشر کنید و آدرس Worker را در `Assets/config.js` قرار دهید، مثال:
`window.SITE_CONFIG={API_BASE:'https://YOUR-WORKER.workers.dev'};`

## فایل دانش‌آموزان
فایل CSV با ستون‌های زیر آماده کنید:
`national_id,first_name,last_name,grade,field,class_name,password`

نمونه:
`1234567890,سارا,احمدی,دهم,ریاضی,۱۰۱,رمز-اختصاصی`

فایل را فقط از مسیر مدیریتی Worker و با کلید `ADMIN_KEY` وارد کنید. رمز عبور قبل از ذخیره‌سازی با PBKDF2 هش می‌شود.

> نکته امنیتی: ورود فقط با کد ملی برای محیط واقعی مدرسه سطح امنیت پایینی دارد. این نسخه طبق خواسته فعلی شما همین روش را پیاده کرده؛ برای استقرار عمومی بهتر است بعداً یک رمز/کد دوم هم اضافه شود.
