# Shooshtar Sampad V2

نسخه بازطراحی‌شده سایت دبیرستان استعدادهای درخشان دوره دوم شهرستان شوشتر.

## ظاهر
- تم واحد آبی، سفید و طلایی
- موبایل‌پسند
- صفحه کادر با فونت و انیمیشن‌های یکپارچه
- قاب متحرک برای جمله «معلمان، چراغ راه آینده‌اند»
- حلقه متحرک مدرن دور عکس همکاران، بدون گل
- قالب استاندارد تصاویر و نمایش بزرگ با Viewer

## بخش‌ها
- افتخارات دسته‌بندی‌شده
- اسناد ثابت مدرسه
- گالری
- صدای مشاور
- پنل دانش‌آموز
- پنل دبیر
- پنل مدیریت
- ورود دانش‌آموزان از Excel
- کارنامه، معدل و جایگاه کلاس
- فایل‌های خصوصی دانش‌آموز
- لینک کلاس آنلاین

## اجرای Backend
```bash
cd Backend
npm install
JWT_SECRET="یک-رشته-طولانی-و-تصادفی" ADMIN_KEY="یک-کلید-مدیریت-طولانی" npm start
```
سپس `http://localhost:3000` را باز کنید.

### نمونه ورود تستی
کد ملی: `1000000001`
رمز: `123456`

برای محیط واقعی این حساب را حذف یا تغییر دهید، JWT_SECRET و ADMIN_KEY واقعی و تصادفی تنظیم کنید. پنل مدیریت و بارگذاری Excel/ویس بدون ADMIN_KEY فعال نمی‌شوند.

## نکته امنیتی
کد ملی و رمز عبور داخل HTML قرار داده نشده‌اند؛ اطلاعات باید در Backend و پایگاه داده نگهداری شوند.
